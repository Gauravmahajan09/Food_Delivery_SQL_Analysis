# 🍔 Food Delivery SQL Analysis Project

## 📌 Project Overview

This project analyzes a Food Delivery database using MySQL 8.0.

The project covers SQL queries from Basic to Advanced level to analyze customers, restaurants, orders, payments, and food items.

## 🛠️ Tools & Technologies

- MySQL 8.0
- SQL
- GitHub

## 🗂️ Database Tables

- customers
- restaurants
- orders
- order_items
